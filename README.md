Maze Generation Project

C++ Program that generates a randomized 70x40 maze that uses Depth-First search with backtracking. The maze starts with
a defined starting point labeled with $, then repearedly carves paths in a randomly selected available direction. When 
there no available directions, the program backtracks to the previous coordinate and searches there until there are no 
more available paths to be carved, creating a full maze with many decoy paths. The endpoint of the maze is labeled with
!. The program keeps track of the correct path and then provides the user with the solution if they request it.
